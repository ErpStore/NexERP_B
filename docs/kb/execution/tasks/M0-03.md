## Task Objective

Remove every database connection string and every signing secret from the repository's
working tree, replace them with configuration read from environment variables or .NET
user-secrets, and make the applications refuse to start when that configuration is
missing or still set to a known default.

This parent task is delivered by three sequential children:

1. **M0-03-01** — the JSON configuration surface (`appsettings.json` in `V.SMART.Web`
   and `V.SMART.Api`).
2. **M0-03-02** — the **hardcoded connection strings in C# source**, which the risk
   register does not mention.
3. **M0-03-03** — fail-fast startup validation, so that a missing or default value is a
   startup error rather than a silent fallback.

## Why This Task Exists

Serves risks **R-01** (live database credentials committed to source control) and
**R-02** (JWT signing secret committed) from
[KB-060](../../risks/technical-debt-register.md), and is a hard precondition for the G0
exit-gate line *"No connection string or JWT secret in the working tree **or** in
`git grep … HEAD`"* ([KB-080 §7](../README.md#exit-gate--g0)).

**KB-060's R-01 action item is incomplete, and this task exists partly to say so.**
R-01 names only `V.SMART.Web/appsettings.json` and `V.SMART.Api/appsettings.json`, and its
action item reads "Move configuration to environment variables / Key Vault". Verification
on 2026-08-12 (INV-029) shows that **three C# source files also carry the same credentials
as string literals** — `ApplicationDbContextFactory.cs`, `MasterDbContextFactory.cs` and
`MauiProgram.cs`. Externalising only the JSON files would leave the SA password and the
commented production credentials sitting in compiled C#, would leave `git grep` on `HEAD`
still returning hits, and would therefore **not** satisfy G0 while appearing to. Child task
**M0-03-02 exists precisely to close that gap.**

Secondary consequence: `docs/kb/risks/technical-debt-register.md` R-01 must be amended by
M0-03-02 so the register stops under-stating the blast radius.

**This task does not rotate anything.** The credentials are published on a public GitHub
repository (INV-029) and must be treated as already compromised. Rotation is **M0-04**, and
it runs in parallel starting immediately. Externalisation without rotation is cosmetic.

## Combined Acceptance Criteria

- [x] No connection string containing a password exists anywhere in the working tree:
      `git grep -n "Password=" -- "V.SMART/"` returns no hits outside `docs/` and
      `V.SMART/V.SMART.Shared/Migrations/`.
- [x] No JWT signing secret literal exists in the working tree; `Jwt:Secret` is supplied
      only by environment variable or user-secrets.
- [x] `V.SMART/V.SMART.Web/appsettings.json` and `V.SMART/V.SMART.Api/appsettings.json`
      contain configuration **keys** with empty or absent values, never credentials, and
      never a commented-out production connection string.
- [x] `ApplicationDbContextFactory.CreateDbContext` and
      `MasterDbContextFactory.CreateDbContext` obtain their connection string from
      configuration/environment, not from a string literal.
- [x] `V.SMART/V.SMART/MauiProgram.cs` obtains the master connection string from
      configuration, not from a string literal, and the three commented alternatives are
      gone.
- [x] `V.SMART.Api` and `V.SMART.Web` both throw at startup, with an actionable message
      naming the missing key, when `ConnectionStrings:MasterDb` is missing or empty.
- [x] `V.SMART.Api` throws at startup when `Jwt:Secret` is missing, shorter than 32 bytes,
      or equal to the known default recorded in
      [KB-060 R-02](../../risks/technical-debt-register.md#r-02--jwt-signing-secret-committed).
- [x] A `README`-level note documents exactly which environment variables / user-secrets
      keys a developer must set to run each host.
- [x] `dotnet build V.SMART/V.SMART.Api/V.SMART.Api.csproj` still reports 0 errors.
- [x] `docs/kb/risks/technical-debt-register.md` R-01 is amended to include the three C#
      files, with `file:line` evidence.

## Rollup Gate Contribution

Contributes to **G0** as follows:

| G0 criterion | Contribution |
|---|---|
| No connection string or JWT secret in the working tree **or** in `git grep … HEAD` | M0-03 delivers the *working tree* half in full. The *history* half is **M0-05** and cannot start until this task and M0-04 are complete. |
| Exposed credentials rotated, confirmed by the person with production access | Not this task. **M0-04.** M0-03 makes the rotated values injectable; it does not rotate them. |
| A fresh environment can be rebuilt from source control alone | M0-03-03's fail-fast validation is what turns a mis-configured fresh environment into a clear startup error instead of a `NullReferenceException` deep inside `TenantDbContextFactory` (`V.SMART/V.SMART.Shared/Services/MultiCompanyService/TenantDbContextFactory.cs:19`). |
| Repository visibility deliberately decided and recorded | Not this task. **M0-04** raises Q-19. |

M0-03 does **not** on its own close R-01 or R-02. Both remain open until M0-04 (rotation)
and M0-05 (history purge) are complete, and R-01 additionally remains open for the
plaintext per-tenant connection strings in the master database `Tenants` table
([KB-014 §Problems for a React SPA, item 5](../../architecture/multi-tenancy.md#problems-for-a-react-spa)),
which is out of scope for all of M0-03 and is tracked as a separate follow-up in M0-04's
inventory.
