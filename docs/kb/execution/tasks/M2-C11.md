## Objective

Remove `frontend/vsmart-erp/` — the Angular 19.2 learning pilot — from the active repository,
now that Q-38 has settled what "adopt" meant: **patterns**, not the directory. Every fact worth
keeping from the pilot was already extracted as text, twice, before this task ever touched the
directory — this task's actual job was verifying that record is complete and then executing
the removal safely.

## Scope

- Confirm `frontend/nexgen-web/` (the Angular 22 workspace `M2-C00`/`M2-C01` built, extended by
  every `M2-C` task since) has no dependency on `frontend/vsmart-erp/` — it does not, by
  construction, but this is verified rather than assumed.
- Tag the pre-removal state, then remove `frontend/vsmart-erp/` (40 tracked files).
- Correct the two places that had drifted while Q-38 was open: `KB-015`'s pilot section (which
  briefly described the *wrong* reading of "adopt" from 2026-08-20–2026-08-27) and `R-34`
  (whose "REVERSED" framing was itself stale, written before `M2-C00` re-specified the stack to
  Angular).

## Out of Scope

- **Building or editing anything in `frontend/nexgen-web/`.** This task removes a directory; it
  does not add application code.
- **Re-deriving what the pilot proved.** `KB-050`'s adopt/reject tables (written by `M2-C00`)
  and this file's own § Retained evidence (below, unchanged from the pre-Q-38 version — it was
  already correct) are the record. Nothing here repeats or second-guesses them.
- **Implementing real auth against the current API contract.** The pilot's `auth.service.ts`
  targets the pre-versioning `/api/auth/login` route (404 today) and stores the JWT in
  `localStorage` (rejected by ADR-004). Building real, working auth is `M2-C02`'s job — see
  `KB-050`'s "do not copy" table for exactly what not to carry forward when that task runs.
