## Why this task exists

[ADR-007](../../decisions/ADR-007-angular-stack.md) selected Angular + PrimeNG on 2026-08-20,
superseding ADR-003's React stack. [KB-050](../../frontend-new/react-architecture.md) — the
frontend architecture proposal that **every `M2-C` task cites as its primary input** — still
describes a React application.

**This task is the gate on the entire `M2-C` tree.** Until KB-050 describes Angular, there is no
authoritative structure to specify the other tasks against, and re-specifying them first would
mean writing detail against a guess.

## Scope

Rewrite KB-050 for Angular. The existing document already carries a section-by-section map, added
when ADR-007 landed, of what is dead and what still binds — **start from that map, do not
re-derive it.**

**Rewrite:**

- *Recommended stack* → ADR-007's table. Do not re-decide it; ADR-007 is authoritative.
- *Project structure* → the Angular layout: standalone components, `core/` / `shared/` /
  `features/`, lazy feature routes.
- *Data-fetching conventions* → typed services over `HttpClient` with explicit `refresh()`.
  TanStack Query is out (ADR-007 records why).
- *Authentication flow* → Angular functional guards and an HTTP interceptor. **Token storage is
  `M2-C02`'s decision**, not this document's — state the constraint (ADR-004) and the open choice,
  and **do not** carry over the pilot's `localStorage` JWT, which is XSS-exposed.
- *Permission-based rendering* → the same 152 × 5 matrix, expressed as a structural directive
  rather than a component wrapper.
- *Error handling* → **this section predates `M2-A06`.** The real contract now exists: rewrite
  against [ADR-002 §4](../../decisions/ADR-002-rest-api-layer.md) and
  `V.SMART/V.SMART.Api/Middleware/ApiProblems.cs`, including that a business-rule refusal is a
  `409` whose `title` carries the service's message **verbatim** (BR-SO-001).

**Keep, with only the framework nouns changed:**

- *Design constraints from the existing system* — facts about the ERP.
- *Document editor pattern* and *Workflow commands* — the core abstraction, a shape rather than a
  library.
- *Performance targets*, *Accessibility*, *What is deliberately not rebuilt*.

**Read the existing Angular pilot** (`frontend/vsmart-erp/`, Angular 19.2 + PrimeNG 19.1) and
record what its structure gets right and where it should not be copied — it has 9 components
including an auth service, guard and interceptor, and `M2-C11` adopts it as the baseline.

## Acceptance criteria

- [ ] KB-050 describes an Angular application end to end; no section instructs React, Vite,
      Mantine, TanStack, Zustand, React Hook Form or Zod as the thing to build.
- [ ] Its `title` and `doc_id` remain **KB-050** — ~20 task files cite it and must not have to
      change twice. The filename may change; if it does, every citation changes in the same commit.
- [ ] The stack section **agrees with ADR-007's table in substance and contradicts it nowhere**,
      names ADR-007 as the authority, and does not restate its rationale.
      **Test:** for every row, the *Concern* and the *Choice* mean the same thing in both
      documents. **Additional clarifying detail in KB-050 is allowed and is not a failure** —
      naming which task decides an open sub-question, or which fallback ADR-007 already sanctions,
      makes the document more useful, not less faithful. What fails is a row that is **absent**,
      names a **different** choice, or asserts something ADR-007 does not support.
      *(Relaxed 2026-08-20. This criterion previously demanded the section match "exactly", and
      attempt 1 was failed on it: a mechanical column diff found 16 of 17 rows byte-identical and
      one that added "`M2-C07`'s call per ADR-007, with AG Grid as the named fallback" — accurate,
      ADR-007-sourced, and an improvement. **The validator applied the criterion correctly; the
      criterion was wrong.** Editing the document to satisfy it would have made KB-050 worse, so
      the criterion changed instead. Byte-equality between two documents with different jobs is
      not a quality bar — it is a copy-paste check that punishes the more useful text.)*
- [ ] The error-handling section matches the **shipped** `ApiProblems` contract, with `file:line`
      evidence.
- [ ] Token storage is stated as an open decision owned by `M2-C02`, with the pilot's
      `localStorage` approach explicitly **not** endorsed.
- [ ] The pilot's hardcoded `http://localhost:5144` in **both** `environment.ts` and
      `environment.prod.ts` is recorded as a defect to remove, not a pattern to copy.
- [ ] The ⛔ STOP banner is removed from KB-050 — superseded by the rewrite itself.
- [ ] The `M2-C01` task file is re-specified for Angular in the same change, since it is the next
      task and its banner otherwise blocks it.
- [ ] No code is written. This is a documentation task.

## Do not

Write any code. Re-decide ADR-007's stack choices — implement them as recorded, and if the ADR is
wrong, say so and stop rather than quietly diverging. Re-specify the whole `M2-C` tree: only
`M2-C01` is in scope here; the rest are re-specified as they come up. Delete the React app —
that is the re-scoped `M2-C01`'s call.
