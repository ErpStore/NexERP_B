## Task Objective

Strip every credential out of the JSON configuration files of `V.SMART.Web` and
`V.SMART.Api`, and replace them with values supplied at run time by .NET user-secrets
(developer machines) or environment variables (servers and CI). After this task, both
`appsettings.json` files declare configuration **shape** only — keys with empty values —
and carry no password, no host, and no signing secret, in either an active line or a
commented-out line.
