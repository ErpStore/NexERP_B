## The atomicity rule — inherited from the parent, and non-negotiable

> **A file's ⛔ banner may only be removed in the same change that removes its React
> instructions.** No file may come to rest banner-removed and React-bearing — that strips the
> only guard stopping a runner from building the wrong stack while leaving the instruction to
> build it. If you cannot finish a file, **leave its banner in place** and report it as not
> done. Half-done is worse than not started.

Attempt 1 of the unsplit parent failed exactly this way across 23 files. Do not repeat it.
